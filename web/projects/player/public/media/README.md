# Player portal demonstration video

`demo-loop.mp4` stands in for an arena video source so the player portal has
something to play out of the box. **It is not a cockfight recording and no live
fight is broadcast anywhere in this application.**

## Playback boundary

The player uses only the bundled demonstration clip. Custom source preferences
are ignored and players cannot configure a broadcast URL.
