# Legacy points archive

The transferable Points module is retired. `/admin/points` now contains only authorized
historical balances, transaction details, filters and CSV exports. Create, credit,
transfer, adjustment and refund controls and API operations have been removed.

Arena Points are the only gameplay balance and are system allocated. No legacy balance
is moved, merged or converted. See the [retirement runbook](../arena-points/README.md)
and [API contract](../api.md#legacy-points-archive).
